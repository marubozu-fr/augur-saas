Language switcher

A compact locale switcher for the public marketing header (desktop dropdown) and the mobile Sheet drawer (block list). It shows the current locale code only — EN / FR, no flags — and each option is a link to the equivalent page in the other locale (/en/pricing ↔ /fr/pricing). It is deliberately secondary: "Sign in" and "Get started" remain the primary header actions. The reusable .lang-switch component lives in styles.css.
