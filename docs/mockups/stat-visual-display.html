Tier 2

Each pattern is a two-outcome split — how often it plays out one way versus the other. The visual reads the edge at a glance; expand Advanced on any card for the exact probability, baseline, sample size and edge.

State · Visual display row (default)

One card per condition. Opening Candle Continuation has two conditions (green / red opening candle), so it renders as two cards; these plus Engulfing and Inside Bars use a bespoke candle glyph + diverging bars. The last card (Gap Fill) is the DEFAULT fallback template (dot + hero % + horizontal split bar) for families without a custom icon. The single context line sits below the row. Every card's Advanced toggle is shown collapsed — the default; the edge / baseline / N detail lives inside it, not in the default view.

Reference · Custom glyph set

The three candle glyphs as a coherent set — same 2.5px round-cap wick, rounded bodies, and a mono timeframe baked into the "signal" candle. Bullish elements use --color-up, bearish use --color-down. Pure inline SVG, no raster assets. The Gap Fill card intentionally has no glyph (default template).
